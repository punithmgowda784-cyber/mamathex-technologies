## Project Files

```text
mamathex-technologies/
├── index.html
├── style.css
├── script.js
└── README.md
```

Keep `index.html`, `style.css`, and `script.js` together in the repository root so the styles and scripts load correctly.

## Run Locally

1. Download or clone this repository.
2. Keep all website files in the same folder.
3. Open `index.html` in a web browser.

You can also use the Live Server extension in Visual Studio Code and open `index.html` with Live Server.

## Publish with GitHub Pages

1. Create a **public** repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. After GitHub Pages finishes deploying, your website will be available at:

   `https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/`

Replace the example URL with your GitHub username and repository name.
